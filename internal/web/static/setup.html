Connect storage

Socrates keeps its settings, password, sign-ins and session list in an S3 bucket, encrypted on this machine before anything leaves it. A new machine pointed at the same bucket comes back exactly where you left off.

Checking
Taking over stops the other Socrates from writing to the bucket. It keeps running, but nothing it does is saved any more. Use this when that machine is gone or you are moving away from it.

Everything in the bucket is encrypted with a key made from this passphrase. It stays on this machine; the bucket only ever sees ciphertext. Lose it and the bucket cannot be read by anyone — keep it somewhere safe. For an existing bucket, enter the passphrase it was set up with.
