Skills

A skill is a program Socrates knows how to operate the way a person does: how it is started, what its screens look like, which keys answer its questions. All of that ships with the app and is kept up to date with it. You decide which ones Socrates may use, what it should use them for, and which models it may run each of them on.

Voice

Your recording is transcribed by an OpenRouter model, picked from the same catalogue as everything else. Reading the answer back is not a model at all: a small voice ships with Socrates and runs on this machine. It costs nothing, needs no key and no account, and there is nothing to pick — the spoken language below is what chooses the voice. Socrates installs it by itself the first time it starts — a 150 MB download, which is what the line below reports on — and the Docker image already has it.
